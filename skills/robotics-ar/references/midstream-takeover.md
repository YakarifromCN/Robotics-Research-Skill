# 中途接入

`MIDSTREAM_TAKEOVER` 是面向已有代码、实验、环境和局部瓶颈项目的附加入口。Supervisor
要把用户断言与仓库观察、agent 推断分开记录，不能静默地用新想法替换当前方法。

执行门槛是：

```text
Project Core + Reconstructed History + Reproduced Baseline + Approved Trial Contract
```

四项未齐全时，运行时只能处于 planning-only 或 blocked。中途接入不是第五个领域阶段；
Idea/Experiment/Writing/Review 仍然是 sibling Skills。

# English

# Midstream Takeover

`MIDSTREAM_TAKEOVER` is an additive entry mode for a project that already has code,
experiments, an environment, and a local bottleneck. The Supervisor records user
assertions separately from repository observations and agent inferences. It never
silently replaces the current method with a new idea.

The execution gate is:

```text
Project Core + Reconstructed History + Reproduced Baseline + Approved Trial Contract
```

Without all four, the runtime remains planning-only or blocked. Midstream takeover is
not a fifth domain phase; Idea/Experiment/Writing/Review remain sibling Skills.
