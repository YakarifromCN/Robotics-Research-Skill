# 人工重新接入

每个 checkpoint、暂停、阻塞、升级和 batch 完成事件都要更新详细的 `report.md` 与
`handoff.md`。报告解释当前研究状态和决策；交接文档记录 hash、分支、进程、fingerprint、
工件路径、精确命令、回滚点和恢复命令。

自然语言纠正必须逐字保留；当范围变化时，将其编译为 `task.md` 和合同 amendment。
恢复前要重新验证 state/events、hash、Git、环境、预算、进程注册表、租约和原始证据。

# English

# Human Re-entry

Every checkpoint, pause, block, escalation, and batch completion updates detailed
`report.md` and `handoff.md`. The report explains current research state and decisions;
the handoff records hashes, branch, processes, fingerprints, artifact paths, exact
commands, rollback point, and resume command.

Natural-language correction is preserved verbatim and compiled into `task.md` plus a
contract amendment when scope changes. Resume revalidates state/events, hashes, Git,
environment, budget, process registry, leases, and raw evidence before continuing.
