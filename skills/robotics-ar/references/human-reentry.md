# English

# Human Re-entry

Checkpoints, pauses, blocks, escalations, and batch completion preserve necessary machine
state and evidence. Explain results in conversation by default, without report files.
Only on explicit user request update categorized `report.md` or `handoff.md` within the
same project, without per-task copies. They may include hashes, branch, processes,
fingerprints, artifact paths, and resume commands.

Natural-language correction is preserved verbatim and compiled into `task.md` plus a
contract amendment when scope changes. Resume revalidates state/events, hashes, Git,
environment, budget, process registry, leases, and raw evidence before continuing.
