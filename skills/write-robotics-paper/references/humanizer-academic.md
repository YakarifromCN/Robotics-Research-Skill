# Humanizer 学术适配

这是基于 Humanizer 3.0.0 的精简适配，供没有独立 Humanizer 安装的离线环境使用。
保留作者的学术声音和全部有依据的信息；风格样例优先于通用语言偏好。

先通读并标记段落中的空洞强调、虚构反方、重复结尾、机械排比、宣传式表达和聊天残留。
再围绕段落主旨改写，最后复查是否增删了事实、主张、数量、单位、引用或适用范围。
微弱线索需要上下文支持，不设删词配额，不判断文字由谁撰写。

保留真实比较、必要限定、安全边界、负面结果、方法定义与不确定性。技术术语、数学符号、
LaTeX 命令、引用键、代码和路径不因语言偏好改变。不能用个人感受、猜测或虚构例子使技术文字“自然”。
减少堆叠限定时，仍须保留影响结论解释的限定；充分支持的结论也不应被改成过度保守的说法。

使用 file/embedded 模式，只写最终正文及简短变更摘要。只读任务仅报告问题。
完成后复验科学主张与结果状态、数字、引用及格式；代码检查不能证明语义等价，语义需人工核对。
用于本仓库说明文档时，以实际代码和测试作为事实依据，不要求虚构论文合同或投稿目标。

来源：https://github.com/blader/humanizer 。本文件为适配，不是上游完整 Skill；许可证见相邻
`humanizer-LICENSE.txt`。不需要联网下载、论文语料或额外领域 packs。

# English

This compact adaptation of Humanizer 3.0.0 supports offline environments without a separate
Humanizer installation. Preserve the author's academic voice and supported information. An author
sample takes precedence over generic stylistic preferences.

Read the passage, mark empty emphasis, invented objections, repeated closers, forced parallelism,
promotional language and chat residue, then rewrite around its point. Recheck facts, claims,
quantities, units, citations and scope. Weak cues require context; impose no deletion quota and
make no authorship judgment.

Preserve real comparisons, necessary qualifications, safety boundaries, negative results, definitions
and uncertainty. Do not alter technical terms, mathematical symbols, LaTeX commands, citation keys,
code or paths for style. Do not invent reactions, guesses or examples. Remove stacked hedges without
losing qualifications that affect interpretation; do not weaken well-supported findings.

Use file or embedded mode: deliver final prose and a brief summary. Read-only tasks only report
findings. Recheck scientific claims, result states, numbers, citations and formatting afterward.
Mechanical checks do not establish semantic equivalence. For repository documentation, ground
claims in code and tests without inventing a manuscript contract or submission target.

Source: https://github.com/blader/humanizer . This is an adaptation, not the complete upstream Skill.
See the adjacent `humanizer-LICENSE.txt`. No network, paper corpus or additional domain packs are required.
