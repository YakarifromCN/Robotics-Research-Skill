# 写作核心合同

Claim Ledger 是写作事实源。任何正向句子必须链接到相容状态的结果；数字由稳定 ID 渲染；引文必须验证存在性与实际支持关系。投稿目标只改变组织与压缩，不改变科学事实。

---

# English

The Claim Ledger is the writing source of truth. Positive statements require compatible results; stable IDs render numbers; citations need existence and entailment checks. A target changes packaging, not scientific facts.
