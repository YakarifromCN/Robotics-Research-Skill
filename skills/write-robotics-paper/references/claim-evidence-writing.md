# 主张—证据写作

每个 load-bearing 句子必须映射到 Claim Ledger。`SUPPORTED` 可写限定范围内正向结论；`PARTIALLY_SUPPORTED` 必须同时引用正向结果与独立边界；`NOT_SUPPORTED` 和 `INCONCLUSIVE` 不得改写为“有效”。数字、引文、图和失败边界分别以稳定 ID 绑定。

正文应包含理解承重主张所需的核心方法与证据；补充材料可承载实现细节，但不能成为唯一支撑位置。

---

# English

Map every load-bearing sentence to the ledger. Partial support requires both a positive result and an independent boundary result. Never upgrade negative or inconclusive evidence. Bind numbers, citations, figures, and failure boundaries with stable IDs. The main text must contain the method and evidence needed to understand each load-bearing claim.
