# 机器人子模式卡

这些卡是检索与审计提示，不是固定答案。每次使用都要补充最近邻来源和失效边界。

## 异质分解

可实例化为接触阶段、任务/残余空间、力/运动双通道、推进/支撑响应、稳定接触/冲击过渡、人/机器人控制权、刚性/柔性结构分解。必须写明触发条件、被改变对象、承重接口、成功条件、常见失败、最小决定性实验、同容量语义负控制和检索词。

## 假二选一拆解

检查社区是否默认只能在性能、稳定性、适应性或可部署性之间二选一。有效贡献必须改变约束结构或保留对象，而不只是调参得到折中点。

## 机制边界

优先寻找“总体性能相近但中介变量不同”的替代机制，以及只在特定阶段消失、反转或提前失效的签名。

# English

Use these as retrieval and audit prompts, never as fixed answers. Instantiate decomposition, false-dilemma, and mechanism-boundary patterns with explicit triggers, changed objects, load-bearing interfaces, success conditions, failure forms, decisive tests, semantic controls, and current nearest-neighbor searches.
