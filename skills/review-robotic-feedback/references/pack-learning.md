# 学习包 / Learning pack

检查训练、验证、测试隔离，数据与演示来源，seed/checkpoint 选择，oracle 信息，sim-to-real、留出条件、失败分布和统计单位。把学习贡献与控制器补偿、硬件变化分开。

Audit train/validation/test separation, data and demonstration provenance, seeds/checkpoints, oracle information, sim-to-real transfer, held-out conditions, failures, and statistical units. Separate learning from controller compensation and hardware changes.
