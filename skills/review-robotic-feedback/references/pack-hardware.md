# 硬件包 / Hardware pack

记录机器人、末端、传感器、批次、标定、固件、驱动、通信、负载、工作空间、急停、安全包络和故障分类。区分硬件故障、协议偏离、abort 与任务失败。

Record robot, end-effector, sensors, hardware batch, calibration, firmware, drivers, communication, load, workspace, emergency stop, safety envelope, and failure classes. Separate hardware faults, protocol deviations, aborts, and task failures.
