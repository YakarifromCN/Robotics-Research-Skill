# Review 阶段的子流形路由

根据稿件的 E/P/C/L/D/H/A/S 向量选择评审关注面，并将每个 finding 绑定到轴、位置、证据锚点和行动。至少检查主轴的证据闭环；跨轴主张还要检查副轴之间是否存在断链。

结合指定 venue 的当前官方 scope、author guide、程序、rebuttal、video、ethics 和 artifact 规则审计适配性。`direct_robotics` 与 `robotics_strong_related` 只改变审计优先级，不产生学术评级。评审分数、factor-fit 和奖项识别都不得被折叠为真实录用概率。

---

# English

Use the manuscript's E/P/C/L/D/H/A/S vector to choose review attention and bind each finding to an axis, location, evidence anchor, and action. Check the evidence loop for every primary axis and inspect cross-axis breaks for integrated claims.

Audit the current official scope, author guide, program, rebuttal, video, ethics, and artifact rules for the specified venue. `direct_robotics` and `robotics_strong_related` change review priority only; reviewer scores, factor fit, and award signals must never be collapsed into an acceptance probability.
