# 人机交互包 / Human-interaction pack

检查参与者层级、任务顺序、学习效应、配对、同意与安全、操作者监督以及人类输入是否被误写成心理或人体动力学结论。

Check participant hierarchy, task order, learning effects, pairing, consent and safety, operator supervision, and whether human input is overstated as psychological or biomechanical evidence.
