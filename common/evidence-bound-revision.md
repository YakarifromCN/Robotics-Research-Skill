# Evidence-bound contribution calibration

Use this contract only when revising or reviewing existing prose. It calibrates
the manuscript in both directions; it is not a generic request for more caution.

1. Keep contribution visibility at or below the frozen evidence ceiling.
2. State the supported, scoped contribution first; place each qualification
   where it changes interpretation (`contribution -> evidence -> qualification`).
3. Distinguish rhetorical defensiveness from epistemically necessary caution.
4. Treat `KEEP` as a first-class result; cue counts are never edit quotas.
5. Use `QUERY` when meaning or authority is unresolved; do not improvise.
6. Preserve evidence function, scope coverage, source status, citation role,
   negative results, rival explanations, and conceptual hierarchy across edits.
7. Strengthen underclaimed prose up to the frozen Claim Ledger ceiling, preserve
   it, or narrow it when evidence requires. Never use the source sentence as the
   ceiling: `semantic claim after <= frozen evidence-bound ceiling`.

Lexical retrieval may identify candidates, but only contextual semantic review
may assign a disposition. Preserve functions and stable evidence objects, not
necessarily duplicate source sentences.
